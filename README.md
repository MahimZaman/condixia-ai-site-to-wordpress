# Condixia AI Site-to-WordPress

Import HTML, CSS, and JavaScript from an AI-generated site and manage the converted site in WordPress.

## Requirements

WordPress 7.0+, PHP 8.2+

## Installation and use

1. Place the plugin files in `wp-content/plugins/condixia-ai-site-to-wordpress/`.
2. Activate **Condixia AI Site-to-WordPress** from **Plugins** in the WordPress dashboard.
3. Open **Condixia → Import Site** to begin an import. Review imported sites under **Condixia → Sites**.
